## YiPie v0.1.6 · 一瞥 v0.1.6

_2026-11-09_

A refreshed look for the panel and settings page, plus fixes for everything found in a full code review: clearer errors from services, more reliable stop / switch / retry, truncated answers marked as such, and citation lookup that reaches into components and same-origin frames.

面板与设置页换了新外观，另外修好了一次全项目审阅发现的所有问题：服务报错说得更清楚，停止、切换与重试更可靠，被截断的回答会标出来，引用定位能找到组件和同源 iframe 里的原文。


### What's new

- Visual refresh of the panel and settings page: the answer's opening conclusion sits in its own card, the reasoning section folds into a card, the follow-up box and send button form one control, loading uses a shimmer, and scrollbars are thinner. All of these animations turn off when the system asks for reduced motion.
- When a service answers 200 with an HTML error page or a JSON error, the panel shows the service's own message instead of “cannot connect”, and no longer retries pointlessly. Vendor-specific lines inside the stream are skipped instead of breaking the answer.
- After the panel fails to open (“cannot open the panel”), clicking the icon or pressing the shortcut tries again; it used to need closing or reloading the page.
- “Stop” takes effect immediately while a model or prompt switch is in progress or the page text is being read, and no request goes out afterwards.
- After a failed model or prompt switch, the menu returns to the one actually in effect; “Retry” redoes the switch and, with “don't summarize on opening”, doesn't start summarizing by itself. A successful switch clears the old error.
- With “don't summarize on opening”, clicking “Summarize this page” before a switch is saved waits for it and uses the new model or prompt.
- Summaries of pages with tables are more accurate: cells are separated by ` | `, so the model no longer matches numbers to the wrong headers.
- Closing the panel also clears the yellow citation highlight on the page.
- The “default” label on the settings page follows switches made in another tab or in the panel menu, and the delete confirmation describes where the default goes correctly.
- Read-only model / prompt lists can no longer open the editor.
- Pressing Enter in the follow-up box while the panel is busy inserts a newline instead of doing nothing.
- The “!” badge on a tab that once said “this page cannot be summarized” clears once a panel opens there successfully.
- Error details have keys removed before being shortened, so no key prefix is left behind; very long error messages from the stream are shortened.
- When an answer hits the length limit or the connection ends early, this is marked under the answer instead of presenting it as complete.
- A very small context window (under 1024) still sends requests; it used to always report “too long”.
- When the extra request body sets `stream_options` and the service rejects it, the request is no longer sent again for nothing.
- A request header value containing a line break is flagged on the settings page; it used to show up as “cannot connect”.
- Citation lookup finds text inside components (shadow DOM) and same-origin iframes, and is faster in very long single paragraphs.
- Settings page: changing only a model name no longer overwrites names another tab just added; “Send test request” uses what's currently in the form; an entry being edited keeps its input when deleted elsewhere; general settings changed in another tab show up here.
- After shrinking the window or zooming, a panel dragged to the edge comes back into view.
- Triggering twice quickly, or a single-page app navigating while the panel opens, no longer leaves the selection panel on another page.
- Clicking the icon on SVG or XML pages says the page can't be summarized.

### Verification / 验证

- `npm run gate`: type check, unit tests, lint and format checks pass.
- Production build, manifest check and bundle budget check pass.
- `npm run verify:release` validates the package; it contains no source maps, `.env*` files, test leftovers or E2E hooks.

### 本版本更新内容

- 面板与设置页的视觉更新：回答的第一段结论单独成卡片，思考过程折叠成卡片，追问框与发送按钮合成一体，加载动画改为流光，滚动条更细；系统开启「减少动画」时这些动画都会关闭
- 服务在 200 里返回 HTML 错误页或一段 JSON 报错时，面板显示服务的原话，不再误报「无法连接」，也不再白白自动重试；流里夹带的厂商自定义行会被跳过，不再打断回答
- 面板打开失败（「无法打开面板」）后，再点图标、按快捷键会重新尝试，原来要关掉或刷新页面
- 「停止」在切换模型或 Prompt 时、读取正文时也立即生效，之后不会再发出请求
- 切换模型或 Prompt 失败后，菜单回到实际生效的那一项；「重试」重新做这次切换，在「打开时不自动总结」的设置下不会直接开始总结；切换成功后旧的失败提示会消失
- 「打开时不自动总结」时，切换还没存好就点「总结此页」，会等切换完成、用新的模型或 Prompt 总结
- 表格页面的总结更准：单元格之间用 ` | ` 隔开，模型不再把数值对错表头
- 关闭面板后，页面上引用定位的黄色高亮会一起清除
- 设置页的「默认」标记会跟着别的标签页或面板菜单的切换更新，删除确认里对默认项去向的说明也随之正确
- 只读的模型 / Prompt 列表不再能打开编辑器
- 面板忙碌时在追问框按 Enter 会换行，不再什么都不发生
- 曾经提示「此页面无法总结」的标签页，后来成功打开面板时图标上的「!」会清掉
- 错误详情先去掉密钥再截断，不会残留密钥前缀；流里发来的超长错误消息会截断显示
- 回答到了长度上限、或连接提前结束时，回答下方会标出来，不再当作完整回答
- 上下文窗口填得很小（1024 以下）时也能发出请求，原来一律提示「太长」
- 额外请求体里自己写了 `stream_options` 时，服务拒绝后不再白白重发一次
- 请求头的值里有换行时，设置页直接提示，原来会误报「无法连接」
- 引用定位能找到组件（shadow DOM）和同源 iframe 里的原文；特别长的单段文本里点引用更快
- 设置页：只改模型名不会再覆盖别的标签页刚加的模型名；「发送测试请求」用表单当前的内容；正在编辑的一项在别处被删除时，填的内容不会消失；别的标签页改了通用设置，本页会跟着更新
- 窗口缩小或页面缩放后，拖到边上的面板会回到可见范围
- 快速连按两次触发、或单页应用在打开面板时换页，选中内容的面板不再串到别的页面
- SVG、XML 文件页面上点图标会提示无法总结
